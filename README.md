# Sistem Absensi WhatsApp — Teaching Factory (TeFa) 11 RPL

Aplikasi berbasis **Laravel** dan **MySQL** untuk pencatatan kehadiran siswa serta pengiriman notifikasi WhatsApp.

## Prasyarat
- PHP >= 8.2 (disarankan Laragon)
- Composer
- MySQL / MariaDB
- Git
